Newspaper Website
An interactive, full-stack school newspaper platform engineered with HTML, CSS, JavaScript, and PHP/MySQL (powered by XAMPP) that proudly secured 3rd Place in the school competition.

This feature-rich platform goes beyond a standard publication site by integrating:

Secure Authentication: A robust user login and registration panel with role-based access control for readers, writers, and editors.

Dynamic Article Management: A comprehensive content management workflow allowing users to create, edit, categorize, and publish articles seamlessly in real time.

Interactive Engagement: Built-in features like comment sections and a fully playable Sudoku game to boost user retention and entertainment.

Responsive Design: A clean, modern UI optimized for seamless browsing across desktop and mobile devices.
